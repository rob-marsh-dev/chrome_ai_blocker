# AI Search Blocker

A Chrome extension that removes AI Overviews and AI Mode from Google Search.

## Install

1. On this page, click **Code > Download ZIP** and unzip it somewhere permanent. Chrome keeps loading the extension from that folder, so deleting or moving it breaks the extension.
2. Go to `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and pick the unzipped folder.

## Update

Updates are not automatic. To get a new version, download the ZIP again, replace the contents of the folder, and click the reload icon on the extension's card in `chrome://extensions`.
